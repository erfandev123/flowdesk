## 9. 6 answers to questions you'll get

**"Is it a subscription app? Do I need to pay monthly?"**
No. It's self-hosted source code. You run it on your own server. Only the
database file needs a disk.

**"Can I change the logo and colors?"**
Yes — Settings. Logo initials, primary color, accent color, currency,
locale, invoice/quote prefixes and default tax. Takes about 2 minutes.

**"Does the client need an account?"**
No. Each client gets a private token URL. They open it, see their invoices
and pay. No email, no password, no signup.

**"Can I add my own payment gateway?"**
Yes. The portal records payments through one clean endpoint, so wiring in
bKash, Stripe or PayPal is a small, well-defined task.

**"What if a client doesn't pay?"**
The dashboard flags it, the aging list sorts by oldest first, and the
reminder generator produces a WhatsApp/SMS/email message with the amount,
the due date and the payment link already filled in.

**"Do I get support?"**
Setup support is included. Ongoing support and custom features are quoted
separately.
